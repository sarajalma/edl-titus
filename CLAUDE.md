Projet : outil d'état des lieux, usage personnel, 1 logement en colocation.
Contraintes non négociables :

* HTML/CSS/JS vanilla, un seul fichier index.html
* Aucun framework, aucune dépendance, aucun build
* Aucun backend, aucune base : localStorage uniquement
* Export PDF via window.print() + @media print. Ne jamais installer jsPDF ou équivalent
* Les données du logement viennent de edl.json, jamais en dur dans le HTML
